# Designreferenzen
`mockups/01–03` = freigegebene Bildsprache für Hauptmasken. `04_storyboard_gesamt` = freigegebener grober Erlebnisfluss; die einzelnen Bildkacheln darin sind KEINE separat entworfenen, pixelgenauen Screens. `fox/` enthält die originale Fuchsreferenz und Entwurfs-Charakterbögen.

KI-generierte Bilder sind **Designreferenzen**, keine Produktionsgrafiken, kein echtes Rive-Rig und keine ausführbare App. Es sind zusätzlich produktionsreife separate Bilder für Cover, Charakterzustände, Siegel, Questpins, Kapitelhintergründe und UI nötig. Bildschirmtext und grafische Details in Bildern können inkonsistent sein; bindend ist der Text des Masterpakets.
